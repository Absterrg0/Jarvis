# Circe UI Agent Prompt

Use the Circe design system and tokens as the source of truth.

Circe must feel:
**calm, capable, warm, focused, premium, operational, and device-agnostic.**

Before adding any element, ask:

1. Does this improve comprehension?
2. Does this help the user act?
3. Is this already communicated elsewhere?
4. Can I remove it?

Hard rules:

- No generic purple/blue AI gradients.
- No neon or cyberpunk styling.
- Do not overuse copper/orange.
- Do not put icons everywhere.
- Do not force device/project/provider selection before user intent.
- Light mode = warm ivory, not sterile white.
- Dark mode = deep midnight-charcoal, not pure black.
- Use the Circe gradient only for logo/orb/hero moments.
- Cards use borders first; shadows remain subtle.
- Use Inter for dense product UI.
- Use the 4px spacing grid.
- Default control radius = ~12px.
- Default card radius = ~16px.
- Mobile touch targets >= 44px.
- One dominant CTA per context.
- Use explicit operational status language.
- Voice mode must feel attentive, not like a phone call.
- Preserve generous whitespace and quiet hierarchy.
- If the result looks like a generic SaaS dashboard, simplify it.
